# Data Model: CSV 词条英文翻译与消歧

## 实体

### 翻译任务

- 输入：本次唯一输入 CSV 的仓库外或仓库内绝对路径；运行时定位仓库根目录内的参考工作簿。
- 输出：同目录的 `<原文件名>_translated.csv` 与 `<原文件名>_translated_glossary_delta.xlsx`。
- 身份：输入路径、输入记录顺序及每行的词条/comment/来源共同标识本次输入记录。
- 状态：处理中、草稿未完成、已完成或失败。只有所有非省略译文非空且所有 CSV 审核事项完成时才是已完成。
- 幂等：重复写入同一输入记录时更新固定输出路径；源记录未变时复用已批准译文和审核决定，不因重跑覆盖用户审批。
- 批次：每批最多 1000 条记录，翻译与 LLM judge 模型调用合计并发上限为 10 路。整批完成后写入固定输出 CSV，再处理下一批；中断时此前完成批次结果保留。
- 局部失败：单候选翻译或检查失败时保留候选和失败原因，继续同批其他独立候选及后续批次；所有批次结束后仍有失败时任务保持未完成。

### CSV 记录

- 字段：原始列映射、数据记录序号、词条、comment、词条来源、英文翻译、审核状态、错误说明。
- 输入要求：存在词条、comment、词条来源、英文翻译列；comment 可为空但不得自行补造语境。
- 输出要求：保留原始列、列序、行序和记录数量；更新英文翻译，并确保“审核状态”和“错误说明”列存在，缺少时按顺序追加。错误说明只记录该行翻译调用或自动检查失败原因，无失败时为空。
- 行审核状态：无需审核、待审核、已批准；另以错误说明记录该行翻译调用或自动检查的失败原因。任一组成词待审则整行待审核；所有相关决定批准后才能变为已批准。

### 词项与参考术语

- 词项来自中文词条的 jieba 分词结果，保留原始词面、所属 CSV 记录、comment、词条来源及匹配到的使用场景。
- 参考术语来自工作簿的中文/英文译法、伪代码术语标记、备注、comment 规则和省略规则。
- 静态术语可加入 jieba 自定义词典；伪代码术语值为“是”的条目不得加入自定义词典，必须按语境选择译法。
- 相同词项与相同 comment 共享译法；不同语境匹配冲突时不得静默选择。

### 翻译候选

- 字段：记录序号、中文词项、comment、使用场景、候选英文、候选来源（参考术语或当前 Agent 模型）、审核状态、脚本检查结论、LLM judge 结论及失败原因。
- 占位符信息：记录原始占位符及出现顺序，供译文校验；花括号占位符须原样同序，编号百分号占位符可重排但标识、格式和数量须保持。
- 完整词条参考匹配优先于词级组合；未知词项由 Agent 结合语境生成自然英文。
- 翻译模型可接收词条、comment、来源及匹配到的术语说明；每批最多 1000 条记录，翻译与 LLM judge 模型调用合计并发上限为 10。
- 对伪代码术语候选，保留当前词条实际匹配到的参考属性（尤其备注），供该词条翻译 prompt 和对应候选的 LLM judge 使用；不将其作为 jieba 自定义词典词条，也不向未命中该术语的调用发送该参考条目。
- 伪代码术语候选依次经过全量脚本检查和全量 LLM judge。未通过者保留为失败草稿并记录原因、阻止任务完成且不进入抽样。每批对通过前两层的候选随机抽查 `max(1, ceil(候选数 × 5%))` 条；抽查发现不符合参考备注的候选时，该批所有伪代码术语候选进入 HITL 全批复核。
- 向 embedding 服务提交前按中文词项去重；TUI 启动任务时自动授权本次任务全部词项，headless 通过交互式 TTY 回调确认一次。授权仅在本次任务有效。稠密向量仅在本次运行内存中使用，不持久化。
- Embedding 外发授权独立于通用权限模式和记忆授权；headless 无 TTY 或用户拒绝时不请求 API，并将任务报告为未完成。

### 冲突组与人工审核事项

- 冲突组包含同一中文词项/同一 comment 的译法不一致，或不同词项/不同 comment 获得相同英文译法的关联记录。
- 对不同中文词项，使用稠密向量余弦相似度；分值大于等于 0.7 表示语义相近候选，低于 0.7 建议使用不同翻译。
- 相同词项但 comment 不同的冲突直接按语境问题进入 HITL，不依赖 embedding 分值。
- 任意冲突都须人工审核；分值和建议不得自动判定同一实体或更改最终翻译。
- 同一冲突组作为一个 HITL 审核事项呈现，包含该组全部相关记录和拟议变更；无关冲突不合并。
- 审核组可包含两条或更多审核记录。每条审核记录必须提供：单词 string、comment string、词条来源 string、翻译 string、翻译描述 string、使用场景 string、utf-8的字节长度 number、字符长度 number。
- 缺少描述或场景时保留空字符串，并标记缺少上下文；不得编造。
- UTF-8 字节长度以 Buffer 编码后的字节数计算；字符长度以 Unicode 码点计数，不使用 UTF-16 code unit 数。

### 增量参考条目

- 统计键：中文词项与相同 comment。
- 计数：本次输入 CSV 中未匹配到适用参考条目的出现次数；达到 3 次（含）时生成候选。
- 字段：中文词项、候选英文、comment、翻译描述、使用场景、出现次数。
- 只写入新建的增量工作簿，不修改版本化参考工作簿。

## 关系与状态

- 一个翻译任务包含多条 CSV 记录；一条 CSV 记录可拆成多个词项和候选。
- 一个冲突组关联两条或更多候选；一次审核结论可影响关联的多条 CSV 记录。
- 已批准翻译在源记录不变的重跑中保留；拒绝同一实体判断后，系统提出不同翻译，更新前仍须人工批准。
- 存在空译文、待审核记录或必要 embedding 结果不可用时，任务不得标记为完成。
