# Data Model: CSV 词条英文翻译与消歧

## 实体

### 翻译任务

- 输入：本次唯一翻译 CSV，以及先前已通过 add 写入本机项目记忆的参考文档；首次使用时先导入仓库根目录内的基线工作簿。
- 输出：同目录的 `<原文件名>_translated.csv` 与 `<原文件名>_translated_glossary_delta.xlsx`。
- 身份：输入路径、输入记录顺序及每行的词条/comment/来源共同标识本次输入记录。
- 状态：处理中、草稿未完成、已完成或失败。只有所有非省略译文非空且所有 CSV 审核事项完成时才是已完成。
- 幂等：重复写入同一输入记录时更新固定输出路径；源记录未变时复用已批准译文和审核决定，不因重跑覆盖用户审批。
- 批次：每批最多 1000 条记录，翻译与 LLM judge 模型调用合计并发上限为 10 路。整批完成后写入固定输出 CSV，再处理下一批；中断时此前完成批次结果保留。
- 局部失败：单候选翻译或检查失败时保留候选和失败原因，继续同批其他独立候选及后续批次；所有批次结束后仍有失败时任务保持未完成。

### CSV 记录

- 字段：原始列映射、数据记录序号、词条、comment、词条来源、英文翻译、审核状态、错误说明。
- 输入要求：存在词条、comment、词条来源、英文翻译列；comment 可为空但不得自行补造语境。
- 输出要求：保留原始列、列序、行序和记录数量；更新英文翻译，并确保“审核状态”和“错误说明”列存在，缺少时按顺序追加。错误说明只记录该行翻译调用或自动检查失败原因，无失败时为空。
- 行审核状态：无需审核、待审核、已批准；另以错误说明记录该行翻译调用或自动检查的失败原因。任一组成词待审则整行待审核；所有相关决定批准后才能变为已批准。

### 词项与参考术语

- 词项来自中文词条的 jieba 分词结果，保留原始词面、所属 CSV 记录、comment、词条来源及匹配到的使用场景。
- 参考术语来自已通过 Mem0 OSS add 到本地向量记忆的中文/英文译法、伪代码术语标记、备注、comment 规则和省略规则；原始工作簿只在 add 阶段解析，不由翻译流程直接读取。
- 静态术语可加入 jieba 自定义词典；伪代码术语值为“是”的条目不得加入自定义词典，必须按语境选择译法。
- 相同词项与相同 comment 共享译法；不同语境匹配冲突时不得静默选择。

### 翻译候选

- 字段：记录序号、中文词项、comment、使用场景、候选英文、候选来源（参考术语或当前 Agent 模型）、审核状态、脚本检查结论、LLM judge 结论及失败原因。
- 占位符信息：记录原始占位符及出现顺序，供译文校验；花括号占位符须原样同序，编号百分号占位符可重排但标识、格式和数量须保持。
- 完整词条参考匹配优先于词级组合；未知词项由 Agent 结合语境生成自然英文。
- 翻译模型可接收词条、comment、来源及匹配到的术语说明；每批最多 1000 条记录，翻译与 LLM judge 模型调用合计并发上限为 10。
- 对伪代码术语候选，保留当前词条实际匹配到的参考属性（尤其备注），供该词条翻译 prompt 和对应候选的 LLM judge 使用；不将其作为 jieba 自定义词典词条，也不向未命中该术语的调用发送该参考条目。
- 伪代码术语候选依次经过全量脚本检查和全量 LLM judge。未通过者保留为失败草稿并记录原因、阻止任务完成且不进入抽样。每批对通过前两层的候选随机抽查 `max(1, ceil(候选数 × 5%))` 条；抽查发现不符合参考备注的候选时，该批所有伪代码术语候选进入 HITL 全批复核。
- 每条候选生成前，workflow 必须以当前词条和 comment 调用记忆 search，最多取得 5 条相关条目，并记录其来源定位；缺少成功 search 不得调用翻译模型。
- LLM judge 使用相同 search 结果作为依据，不额外注入整份词典；judge 调用同样必须可追溯到对应的检索结果。
- 冲突相似度的去重词项 embedding 可在本次任务内存中计算；参考记忆由 Mem0 OSS 生成 embedding 并持久保存在本地 Qdrant。
- search query/冲突词项的外发遵循任务级授权；参考文档 add 的外发授权独立于任务授权，且仅在该次操作需要外发尚未索引的新内容/更新内容时确认一次。同来源、同内容已索引时本地跳过，无需授权；拒绝或无 TTY 时不发送且导入失败。
- 外发授权独立于通用权限模式；检索不得自动视为 add 外发授权。

### 参考记忆条目与导入

- 参考记忆条目字段：稳定条目 ID、source ID、来源文件名、来源 SHA-256、sheet 名、行号、中文词项、英文译法、comment/场景、属性/备注、Embedding 模型版本、向量。
- 记忆库位置：本机 Qdrant 服务数据目录为 `dataHome()/memory/csv-term-translation/qdrant/storage`；服务只监听 loopback，Mem0 TypeScript SDK 通过 `http://127.0.0.1:6333` 访问。项目 collection 按稳定 `project-key` 隔离；来源清单位于 `dataHome()/memory/csv-term-translation/projects/<project-key>/source-manifest.json`，记录来源状态、保留版本及 active-version 指针。数据不进入仓库版本控制。
- add 输入：仓库版本化的初始 XLSX，或用户明确提交的同格式 XLSX 参考工作簿。翻译 CSV、翻译结果和未审核候选不自动 add。
- 身份与幂等：Mem0 条目 metadata 带 `source ID + source SHA-256 + chunk ID + active-version key`；来源清单记录每个 source 的保留版本、状态和 active key。同来源同内容跳过；更新时先完整解析并通过 Mem0 写入新版本，再原子切换清单中的 active key，旧版本保留。search 将当前 key 集合传入 Mem0 元数据过滤，只返回未软删除来源的 active version；切换失败时旧版本继续可见，新版本不可见。
- Mem0 适配：通过 `mem0ai/oss` 的 `Memory` 调用 add/search；add 使用 `infer: false` 保存原始术语片段，不运行记忆提取 LLM。Qdrant 配置使用 loopback `url` 和项目 collection，不使用 TypeScript REST client 不支持的嵌入式 `path`；每次 add/search 用稳定 `userId` 隔离项目。动态加载 SDK 前关闭 Mem0 telemetry，并关闭 Qdrant 服务 telemetry。
- 授权：每次 add 若需实际外发尚未索引的新内容或更新内容，在发送前确认一次；同来源同内容已索引时本地跳过且无需授予外发权限。授权被拒绝或 API/本地写入失败时不得标记来源可用。
- 删除与恢复：用户明确请求移除来源时，在来源清单中将其标记为软删除并清除 active 指针；Qdrant 中的来源版本继续保留，但 search 过滤所有软删除来源。恢复或回滚时，用户指定保留的版本，系统原子恢复来源状态并将该版本设为 active；失败时不改变原有状态。以上操作仅修改本地清单，不调用 Embedding API。
- search：以当前词项及必要的 comment/使用场景调用 Mem0；这些查询文本遵循本次任务级 Embedding 授权。元数据过滤限定当前项目和 active source version，最多返回 5 个片段，包含记忆文本、相关度和来源定位；不同项目不可互查。
- 记忆不可读、初始化失败或 search 失败时，翻译任务标记为未完成且不得绕过记忆调用模型。

### 冲突组与人工审核事项

- 冲突组包含同一中文词项/同一 comment 的译法不一致，或不同词项/不同 comment 获得相同英文译法的关联记录。
- 对不同中文词项，使用稠密向量余弦相似度；分值大于等于 0.7 表示语义相近候选，低于 0.7 建议使用不同翻译。
- 相同词项但 comment 不同的冲突直接按语境问题进入 HITL，不依赖 embedding 分值。
- 任意冲突都须人工审核；分值和建议不得自动判定同一实体或更改最终翻译。
- 同一冲突组作为一个 HITL 审核事项呈现，包含该组全部相关记录和拟议变更；无关冲突不合并。
- 审核组可包含两条或更多审核记录。每条审核记录必须提供：单词 string、comment string、词条来源 string、翻译 string、翻译描述 string、使用场景 string、utf-8的字节长度 number、字符长度 number。
- 缺少描述或场景时保留空字符串，并标记缺少上下文；不得编造。
- UTF-8 字节长度以 Buffer 编码后的字节数计算；字符长度以 Unicode 码点计数，不使用 UTF-16 code unit 数。

### 增量参考条目

- 统计键：中文词项与相同 comment。
- 计数：本次输入 CSV 中未匹配到适用参考条目的出现次数；达到 3 次（含）时生成候选。
- 字段：中文词项、候选英文、comment、翻译描述、使用场景、出现次数。
- 只写入新建的增量工作簿，不修改版本化参考工作簿。

## 关系与状态

- 一个翻译任务包含多条 CSV 记录；一条 CSV 记录可拆成多个词项和候选。
- 一个冲突组关联两条或更多候选；一次审核结论可影响关联的多条 CSV 记录。
- 已批准翻译在源记录不变的重跑中保留；拒绝同一实体判断后，系统提出不同翻译，更新前仍须人工批准。
- 存在空译文、待审核记录、必要 embedding 结果不可用或必要记忆 search 失败时，任务不得标记为完成。
